# Obsidian — the agent-UI shopping framework, demoed on Halden

Obsidian is a framework for agent-built shopping UIs, and it is not a chatbot. There is no transcript: you type into a single command bar, and the agent files its answer into tabs: product comparisons with graphs, spec explainers, order tracking. It then edits those tabs in place as you refine what you want. The UI is generated by models on Azure AI Foundry through [A2UI](https://a2ui.org) and rendered by our own React components, so every pixel and animation stays on-brand. Buttons inside the generated UI (save, add to cart, buy, track) act on real data through deterministic backend code.

Obsidian is client- and domain-agnostic. Each store plugs in as a **cartridge**: its data, its data model and seed, and its presentation config (brand, spec glossary, product renders, diagrams, category-pairing rules). **Halden**, a fictional electronics retailer with a synthetic dataset, is the first cartridge; it exists only to demo Obsidian during development. **Haier** is the next cartridge: real data and backend from the data-agent teammate, and the final demo runs on it.

**Status:** milestone 2, the first working demo, is done and merged: type a command, a tab opens and the model builds a comparison page with A2UI; the next command edits it in place; "Add to cart" works. Milestone 1, the product spec, is done and approved; milestone 3 builds it. The Haier intake comes after milestone 3 (milestone H). See [ROADMAP.md](ROADMAP.md) and [Run the demo](#run-the-demo).

## Quickstart

Prerequisites: [uv](https://docs.astral.sh/uv/), Python 3.12, Node 22, pnpm 10. Run everything from the repo root.

```bash
# 1. See the concept: open mockup/index.html in a browser (double-click works)

# 2. Install dependencies
uv sync --all-packages --directory backend
pnpm --dir web install

# 3. Install the git hooks (once per clone)
uv run --project backend pre-commit install --install-hooks -t pre-commit -t commit-msg -t pre-push

# 4. Run every check (the same ones CI runs)
python scripts/check.py all

# 5. Run the apps: both at once (Ctrl+C stops both)
python scripts/dev.py

#    or one per terminal
uv run --directory backend uvicorn obsidian_agent.app:create_app --factory --reload   # agent: http://127.0.0.1:8000/health
pnpm --dir web dev                                                                  # web: http://localhost:5173
```

On macOS/Linux use `python3` if `python` isn't on your PATH.

## Run the demo

The demo calls the Azure deployment named in the repo root's `.env` (`AZURE_FOUNDRY_ENDPOINT`, `AZURE_FOUNDRY_API_KEY`, `MODEL_UI_DEPLOYMENT`; see `.env.example`). Every command is a real model call on that deployment, so it costs tokens; without the settings the command bar answers "Missing settings: …".

```bash
# both at once: the agent on http://127.0.0.1:8000, the web app on http://localhost:5173
python scripts/dev.py

# or one per terminal
# terminal 1: the agent, on http://127.0.0.1:8000
uv run --directory backend uvicorn obsidian_agent.app:create_app --factory --reload

# terminal 2: the web app, on http://localhost:5173 (Vite proxies /api to the agent)
pnpm --dir web dev
```

Open <http://localhost:5173/?probe>. `?probe` adds a small panel in the bottom-left corner that counts how many times each part of the page has mounted, so you can see that an edit mounts only the new section (the old ones stay at 1). Leave it off for a clean page.

Try, in order: "Compare 3 laptops for video editing under €2,000", then "Add colour accuracy for grading", then "Only OLED", then "Add to cart" on the pick. The agent keeps one tab and one cart in memory: a reload brings back the page and the cart as they were. To start over, restart the agent (Ctrl+C, run it again) and then reload the page.

The one live test (a real build and edit against the deployment) is skipped unless `OBSIDIAN_LIVE=1`. Run it alone with `--no-cov`, because a single test falls under the 80 % coverage gate:

```bash
OBSIDIAN_LIVE=1 uv run --directory backend pytest packages/agent/tests/test_page_agent.py::test_live_build_then_edit -s -q --no-cov
```

In PowerShell:

```powershell
$env:OBSIDIAN_LIVE=1; uv run --directory backend pytest packages/agent/tests/test_page_agent.py::test_live_build_then_edit -s -q --no-cov; Remove-Item Env:OBSIDIAN_LIVE
```
