# Halden — assistant by Obsidian

Halden is a retail shop whose assistant, Obsidian, is not a chatbot. There is no transcript: you type into a single command bar, and the assistant files its answer into tabs: product comparisons with graphs, spec explainers, order tracking. It then edits those tabs in place as you refine what you want. The UI is generated by models on Azure AI Foundry through [A2UI](https://a2ui.org) and rendered by our own React components, so every pixel and animation stays on-brand. Buttons inside the generated UI (save, add to cart, buy, track) act on real data through deterministic backend code.

**Status:** sub-project 0 of 5: foundation. The repo has its layout, checks and documents; the product itself starts in sub-project 1. See [ROADMAP.md](ROADMAP.md).

## Quickstart

Prerequisites: [uv](https://docs.astral.sh/uv/), Python 3.12, Node 22, pnpm 10. Run everything from the repo root.

```bash
# 1. See the concept: open mockup/index.html in a browser (double-click works)

# 2. Install dependencies
uv sync --all-packages --directory backend
pnpm --dir web install

# 3. Install the git hooks (once per clone)
uv run --project backend pre-commit install --install-hooks -t pre-commit -t commit-msg -t pre-push

# 4. Run every check (the same ones CI runs)
python scripts/check.py all

# 5. Run the apps
uv run --directory backend uvicorn halden_agent.app:create_app --factory --reload   # agent: http://127.0.0.1:8000/health
pnpm --dir web dev                                                                  # web: http://localhost:5173
```

On macOS/Linux use `python3` if `python` isn't on your PATH.
